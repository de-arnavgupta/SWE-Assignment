## 2. Recording Instructions for Student

1. **Tools:** Use Mac built-in screen recorder (`Cmd + Shift + 5`) or [OBS Studio](https://obsproject.com/). Ensure your microphone is selected.
2. **Resolution:** 1080p (1920x1080) at 30 fps recommended.
3. **Walkthrough Flow (Follow `PRESENTATION-SCRIPT.md` strictly):**
   - Present slides (what you built & architecture).
   - Codebase structure in VS Code.
   - GitHub Actions CI/CD pipeline running green.
   - Terraform `terraform plan` output.
   - Argo CD GitOps synchronization.
   - Kubernetes `kubectl get all -n mentorsync`.
   - Prometheus Targets (`UP`) and Grafana Dashboard.
4. **File Placement:**
   - Save your final recording as `presentation.mp4`.
   - If the file is under 100 MB: place directly at `demo/presentation.mp4`, commit, and push.
   - If the file exceeds 100 MB (GitHub file size limit): create a GitHub Release (e.g. `v1.0.0`) on your repository `https://github.com/de-arnavgupta/SWE-Assignment/releases`, upload `presentation.mp4` as a release binary asset, and link it here in this file.
